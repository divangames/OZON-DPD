# Product
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
Vite, выбор реализации делегирован пользователем. Сначала работающий сайт, без отдельного графического макета.
## Users
Продавцы OZON, которым нужна интеграция доставки DPD.
## Product Purpose
Сайт-презентация сервиса API OZON × DPD, переход в личный кабинет.
## Capabilities and Constraints
Информационная структура cdek-ozon.ru, адаптированная под DPD. Достоверность функций проверяется в кабинете. Не переносить статистику CDEK как статистику DPD.
## Brand Commitments
Логотип и favicon из images, фирменные цвета OZON и DPD. Современный, ненагруженный сайт. Пользователь выбрал шрифт Montserrat и отклонил первую визуальную версию как устаревшую.
## Evidence on Hand
Исходный сайт cdek-ozon.ru, кабинет space.dpd-ozon.ru, локальная папка info с приватными доступами. 28 октября пользователь предоставил внутренний доступ: исследованы интеграции OZON и DPD, тарифные связи и модуль товаров. Подтверждены выбор дешёвой услуги, отдельные грузоместа, простой расчёт габаритов, уведомления об ошибке в Telegram и импорт товаров. Не публиковать info, сессии и реквизиты.
## Operating Context
GitHub divangames/OZON-DPD, GitHub Pages и VPS. Папка сайта на VPS OZON-DPD.

## Уточнение владельца: стоимость
Сервис бесплатный для клиентов. На публичном сайте не показывать платные тарифы, ограничения тестового периода и доплату за магазин из исходного сайта-образца.
