# OZON × DPD

Адаптивный сайт-презентация интеграции на Vite. Montserrat, авторская WebGL-сцена Three.js, интерактивный процесс, четыре реальных экрана кабинета, бесплатное подключение и FAQ. Тяжёлая 3D-часть загружается отдельным модулем; без WebGL остаётся текстовая связка, reduced motion останавливает движение.

## Адреса

- Основной сайт: https://dpd-ozon.ru/
- GitHub Pages: https://divangames.github.io/OZON-DPD/
- Кабинет сервиса: https://space.dpd-ozon.ru/

## Запуск

Требуется Node.js 22.12+ или 24+. Откройте `start.bat`:

1. Запуск локально: установка зависимостей при необходимости, Vite и браузер.
2. Открыть опубликованный сайт на GitHub Pages.
3. Собрать, создать коммит, отправить main и опубликовать GitHub Pages.
4. Собрать и опубликовать GitHub Pages без коммита исходников.
5. Собрать и загрузить сайт на VPS.

Дополнительно: `install.bat`, `dev.bat`, `build.bat`, `preview.bat`, `deploy.bat`.

```powershell
npm ci
npm run dev
npm run build
npm run preview
npm run check
```

`check` проверяет готовую сборку на десяти ширинах от 320 до 1920 px, отсутствие переполнений, ошибок HTTP, битых картинок и внутренних ссылок, загрузку 3D, все вкладки кабинета, отсутствие платных тарифов, этапы, FAQ и мобильное меню. Требуется установленный Microsoft Edge; URL задаётся через `CHECK_URL`.

`npm run check:tutorials` дополнительно проверяет видеоинструкции на семи ширинах: отсутствие фоновой загрузки MP4, переключение роликов, настоящее воспроизведение и перемотку на десктопе и телефоне, управление с клавиатуры, меню и HTTP Range сервера. `PW_HEADLESS=false` показывает браузер во время проверки.

## Видеоинструкции

Раздел `#tutorials` содержит три ролика владельца из `video/load`: подключение интеграции (2:08), бесплатная доставка для покупателя (1:03) и платная доставка для покупателя (1:37). Публичные MP4 и WebP-обложки находятся в `public/tutorials`, попадают в `dist` и загружаются на VPS обычной командой публикации. Видео H.264/AAC, без перекодирования, с индексом в начале файла (`faststart`). Плеер использует `preload="none"`, не запускается автоматически и сохраняет встроенные элементы управления браузера. Происхождение файлов — `public/tutorials/provenance.json`.

## Форма и Telegram

Внизу страницы (`#contact`) посетитель оставляет имя и контакт через телефон, Telegram или MAX. Успех показывается после подтверждения доставки Telegram. Ошибка сохраняет ввод; повтор подтверждённой заявки с тем же UUID не создаёт второе сообщение.

Локальный `info/Telegram.txt` содержит `TELEGRAM_BOT_TOKEN=...` и `TELEGRAM_CHAT_ID=...`; он исключён из Git и сборки. `npm run deploy:leads` устанавливает `server/leads.py`, отдельный systemd-сервис и прокси `/api/leads` только в виртуальном хосте dpd-ozon.ru. Секреты: `/etc/ozon-dpd-leads.env` (600), база: `/var/lib/ozon-dpd-leads/leads.sqlite3`; оба пути вне каталога сайта. Обработчик слушает только 127.0.0.1:4192. Незавершённые доставки сохраняются в базе, а браузер получает ошибку для повторной попытки. GitHub Pages — статическая копия; работающий обработчик формы находится на основном VPS.

`python server/test_leads.py` проверяет доставку через локальный имитатор Telegram, ошибки, повтор, валидацию, источник запроса и ограничения частоты. `npm run check:form` проверяет форму на 1440/768/390/320px с имитацией API и не отправляет сообщений в Telegram.

Прокрутка мышью на десктопе — Lenis, появления — GSAP; жесты телефона остаются нативными. Reduced motion поддерживается. Файлы `public` копируются при сборке побайтово через `vite.config.mjs`, чтобы обходить сбои CopyFile для MP4 на рабочем Windows-томе.

## Публикация

Экраны кабинета открываются в модальном `dialog`: описание под картинкой, стрелки, клавиши ←→, свайпы и увеличение кнопкой «+». Escape закрывает окно и возвращает фокус в кабинет. `npm run check:gallery` проверяет галерею с настоящими touch-событиями, единственный раскрытый ответ FAQ и четвёртый этап на 1440/768/390/320px. FAQ плавно меняет высоту через CSS Grid. Успех формы — отдельный экран с анимированной зелёной галочкой и кнопкой новой заявки; reduced motion показывает готовую галочку сразу.

`npm run deploy:pages` публикует **только содержимое dist** в ветку `gh-pages`. Настройка Pages выполняется через GitHub API с доступом Git Credential Manager; токен не записывается в файлы и не выводится. Если API недоступен, выберите в GitHub → Settings → Pages → gh-pages / root. Обновление страницы занимает несколько минут.

`npm run deploy:vps` читает локальный `info/VPS.txt` и загружает `dist` через SFTP в `/var/www/OZON-DPD`. Существующие сайты и чужие файлы не удаляются. Для первого подключения домена используйте конфигурацию `deploy/nginx.conf` после выпуска сертификата. HTTPS обслуживается отдельным Nginx-хостом, сертификат обновляет certbot.timer.

## Материалы и ограничения

Информационная основа — предоставленный пользователем https://cdek-ozon.ru/, с адаптацией перевозчика к DPD. Статистика, отзывы и история CDEK не выдаются за доказательства DPD. По прямому уточнению владельца сервис бесплатный для клиентов. Платные тарифы, тестовый лимит и доплата за магазин удалены. Стоимость доставки остаётся отдельной по договору DPD.

После получения почты и пароля исследованы реальные разделы: интеграции OZON/DPD, связи тарифов, товары. В галерее используются авторизованные скриншоты `public/images/cabinet-{dpd,ozon,tariffs,products}.webp`. Почта, поля ввода и клиентские реквизиты закрыты при съёмке. Настройки и товары аккаунта не менялись. Схема процесса помечена как демонстрация.

Подтверждённые в кабинете возможности: выбор самой дешёвой доступной услуги DPD, отправка товаров отдельными местами, простой расчёт габаритов, Telegram-уведомления о невозможности регистрации, импорт товаров и связи способов доставки.

Основные CTA ведут в существующий сервис. На презентационной странице нет формы, имитирующей отправку заявки, и нет хранения API-ключей посетителя.

Логотип и favicon предоставлены пользователем. Montserrat выбран пользователем, хранится локально; лицензия — `public/fonts/Montserrat-OFL.txt`. Three.js распространяется по MIT. Происхождение изображений: `public/images/provenance.json`. Концепция второй версии: студийная скульптурная связь двух сервисов. Генератор иллюстраций оказался недоступен, вместо растровой иллюстрации реализована живая 3D-сцена. Дизайн-проверки сохранены в `.impeccable`.

## Приватные данные

`info/`, `.private/`, `.env*`, `node_modules/`, `dist/` и тестовые артефакты исключены из Git. В публичную сборку попадает только `public` и скомпилированный `src`. Доступы сервера и кабинета в сайт не включаются.
