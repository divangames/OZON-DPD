# OZON × DPD

Адаптивный сайт-презентация интеграции на Vite. Montserrat, авторская WebGL-сцена Three.js, интерактивный процесс, четыре реальных экрана кабинета, переключение тарифа и FAQ. Тяжёлая 3D-часть загружается отдельным модулем; без WebGL остаётся текстовая связка, reduced motion останавливает движение.

## Адреса

- Основной сайт: https://dpd-ozon.ru/
- GitHub Pages: https://divangames.github.io/OZON-DPD/
- Кабинет сервиса: https://space.dpd-ozon.ru/

## Запуск

Требуется Node.js 22.12+ или 24+. Откройте `start.bat`:

1. Запуск локально: установка зависимостей при необходимости, Vite и браузер.
2. Открыть опубликованный сайт на GitHub Pages.
3. Собрать, создать коммит, отправить main и опубликовать GitHub Pages.
4. Собрать и опубликовать GitHub Pages без коммита исходников.
5. Собрать и загрузить сайт на VPS.

Дополнительно: `install.bat`, `dev.bat`, `build.bat`, `preview.bat`, `deploy.bat`.

```powershell
npm ci
npm run dev
npm run build
npm run preview
npm run check
```

`check` проверяет готовую сборку на 320/390/768/1280/1440 px, отсутствие переполнений, ошибок HTTP, битых картинок и внутренних ссылок, загрузку 3D, все вкладки кабинета, тарифы, этапы, FAQ и мобильное меню. Требуется установленный Microsoft Edge; URL задаётся через `CHECK_URL`.

## Публикация

`npm run deploy:pages` публикует **только содержимое dist** в ветку `gh-pages`. Настройка Pages выполняется через GitHub API с доступом Git Credential Manager; токен не записывается в файлы и не выводится. Если API недоступен, выберите в GitHub → Settings → Pages → gh-pages / root. Обновление страницы занимает несколько минут.

`npm run deploy:vps` читает локальный `info/VPS.txt` и загружает `dist` через SFTP в `/var/www/OZON-DPD`. Существующие сайты и чужие файлы не удаляются. Для первого подключения домена используйте конфигурацию `deploy/nginx.conf` после выпуска сертификата. HTTPS обслуживается отдельным Nginx-хостом, сертификат обновляет certbot.timer.

## Материалы и ограничения

Информационная основа — предоставленный пользователем https://cdek-ozon.ru/, с адаптацией перевозчика к DPD. Статистика, отзывы и история CDEK не выдаются за доказательства DPD. Тарифы 3 800 / 4 800 / 5 800 ₽, дополнительный магазин 1 500 ₽ и тест на 20 заказов перенесены из образца с видимым уточнением актуальности для DPD. Период оплаты в образце не указан, поэтому не придуман.

После получения почты и пароля исследованы реальные разделы: интеграции OZON/DPD, связи тарифов, товары. В галерее используются авторизованные скриншоты `public/images/cabinet-{dpd,ozon,tariffs,products}.webp`. Почта, поля ввода и клиентские реквизиты закрыты при съёмке. Настройки и товары аккаунта не менялись. Схема процесса помечена как демонстрация.

Подтверждённые в кабинете возможности: выбор самой дешёвой доступной услуги DPD, отправка товаров отдельными местами, простой расчёт габаритов, Telegram-уведомления о невозможности регистрации, импорт товаров и связи способов доставки.

Основные CTA ведут в существующий сервис. На презентационной странице нет формы, имитирующей отправку заявки, и нет хранения API-ключей посетителя.

Логотип и favicon предоставлены пользователем. Montserrat выбран пользователем, хранится локально; лицензия — `public/fonts/Montserrat-OFL.txt`. Three.js распространяется по MIT. Происхождение изображений: `public/images/provenance.json`. Концепция второй версии: студийная скульптурная связь двух сервисов. Генератор иллюстраций оказался недоступен, вместо растровой иллюстрации реализована живая 3D-сцена. Дизайн-проверки сохранены в `.impeccable`.

## Приватные данные

`info/`, `.private/`, `.env*`, `node_modules/`, `dist/` и тестовые артефакты исключены из Git. В публичную сборку попадает только `public` и скомпилированный `src`. Доступы сервера и кабинета в сайт не включаются.
